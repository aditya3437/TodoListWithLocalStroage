# 📝 Todo List with Local Storage

A simple and responsive **Todo List App** built with **React** that allows users to add, mark complete, and delete tasks.  
Tasks are stored in the browser's **localStorage**, so your todos remain saved even after refreshing the page.

---

## 🚀 Features
- ➕ Add new tasks
- ✅ Mark tasks as complete/incomplete
- ❌ Delete tasks
- 💾 Data persistence using **localStorage**
- 🎨 Clean and modern UI design
